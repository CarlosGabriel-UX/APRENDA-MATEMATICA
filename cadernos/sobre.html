ℹ️ Sobre o projeto

O que é o Aprenda Matemática, como o conteúdo é feito e como contribuir.

Nesta página

O que é

O Aprenda Matemática é um site gratuito para quem estuda matemática e raciocínio lógico para concursos públicos. A proposta é ser prático: teoria curta, atalhos que economizam tempo na prova, pegadinhas que as bancas costumam usar e questões com explicação imediata.

Para quem é

  • Quem está começando e precisa de uma base organizada.
  • Quem já estudou, mas perde tempo demais nas questões de matemática.
  • Quem quer revisar rápido antes da prova.

Como o conteúdo é feito

  • Todo o texto, os exemplos e as questões são originais, escritos para este projeto. Nada é copiado de apostilas ou provas.
  • As questões seguem o estilo das provas de concurso, mas não são questões oficiais de nenhuma banca.
  • As trilhas por banca descrevem perfis típicos. Confira sempre o edital do seu concurso.

Seus dados

O site não tem cadastro nem login. O progresso, o tema escolhido e o caderno de erros ficam salvos só no seu navegador. Se você limpar os dados do navegador ou trocar de aparelho, eles não vão junto.

Como contribuir

O código e o conteúdo estão abertos no GitHub.

  • Achou um erro de conta ou de digitação? Abra uma issue contando em qual caderno.
  • Quer sugerir um assunto ou uma questão? Também pode ser por issue.
  • Sabe mexer com HTML? O README explica como editar e criar cadernos.
