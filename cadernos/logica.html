Proposições

Proposição é uma frase declarativa que pode ser julgada como verdadeira (V) ou falsa (F), nunca as duas.

Não são proposições: perguntas ("Que horas são?"), ordens ("Feche a porta."), exclamações ("Que lindo!"), frases sem sentido completo e sentenças abertas com variável ("x + 2 = 5", "Ele é médico").

Pegadinha

"Esta frase é falsa" é um paradoxo e não é proposição. Já "2 + 2 = 5" é proposição: é falsa, mas pode ser julgada.

Conectivos e quando cada um é verdadeiro

ConectivoSímboloÉ verdadeiro quando…
Negação: não p~pp é falsa
Conjunção: p e qp ∧ qas duas são V
Disjunção: p ou qp ∨ qpelo menos uma é V
Disjunção exclusiva: ou p ou qp ⊻ qexatamente uma é V
Condicional: se p, então qp → qsempre, exceto V → F
Bicondicional: p se e somente se qp ↔ qas duas têm o mesmo valor
Atalho: decore só quando é FALSO
  • E é falso se alguma for F.
  • OU é falso só se as duas forem F.
  • SE…ENTÃO é falso só em "Vera Fischer" (V → F).
  • SE E SOMENTE SE é falso quando os valores são diferentes.
Outras formas do condicional

"Se p, então q" também aparece como: "q, se p", "p implica q", "p é condição suficiente para q", "q é condição necessária para p", "quando p, q", "todo p é q".

Tabela-verdade

Com n proposições simples, a tabela tem 2ⁿ linhas. Com 3 proposições, 8 linhas.

  • Tautologia: verdadeira em todas as linhas (ex.: p ∨ ~p).
  • Contradição: falsa em todas (ex.: p ∧ ~p).
  • Contingência: nem uma nem outra.
Atalho: procure a linha que derruba

Para saber se algo é tautologia, não monte a tabela inteira. Tente fazer a proposição dar F. Se conseguir, não é tautologia. Para um condicional, isso é tentar V no antecedente e F no consequente.

Atalho: negação do condicional = "Mané"

MAntém a primeira, Nega a segunda, troca por E.

"Se chove, então levo guarda-chuva" → "Chove e não levo guarda-chuva".

Pegadinha

A negação de "Todo político é honesto" não é "Nenhum político é honesto". É "Algum político não é honesto". Basta um contraexemplo para derrubar o "todo".

E a negação de uma condicional nunca é outra condicional.

Equivalências

Duas proposições são equivalentes quando têm a mesma tabela-verdade. As duas que mais caem:

p → q ≡ ~q → ~p   (contrapositiva) p → q ≡ ~p ∨ q
Atalho: "volta negando" e "Neymar"

Contrapositiva: inverte a ordem e nega as duas. "Se estudo, passo" ≡ "Se não passo, não estudei".

Ne-Y-Mar: Nega a primeira, Mantém a segunda, troca por ou. "Se estudo, passo" ≡ "Não estudo ou passo".

Não são equivalentes

"Se p, então q" não equivale a "Se q, então p" (recíproca) nem a "Se não p, então não q" (inversa). As bancas colocam essas duas como armadilha.

Argumentos e diagramas

Um argumento é válido quando, sendo as premissas verdadeiras, a conclusão é obrigatoriamente verdadeira. A validade depende da forma, não do conteúdo.

Atalho: comece pela premissa simples

Nas questões de "considere verdadeiras as premissas", procure a premissa que é uma proposição simples (ou uma conjunção). Ela já é V, e os valores se propagam para as outras.

Premissas: "Se Ana viaja, Bruno fica." "Se Bruno fica, Carla trabalha." "Carla não trabalha." O que se conclui?

"Carla não trabalha" é V, então "Carla trabalha" é F.

"Se Bruno fica, Carla trabalha" é V com consequente F, logo o antecedente é F: Bruno não fica.

"Se Ana viaja, Bruno fica" é V com consequente F, logo Ana não viaja.

Conclusão: Ana não viaja, Bruno não fica, Carla não trabalha.

Quantificadores com diagramas

Para "todo", "algum" e "nenhum", desenhe conjuntos:

  • Todo A é B: o círculo A dentro do círculo B.
  • Algum A é B: os círculos se cruzam (com certeza há elemento na interseção).
  • Nenhum A é B: círculos separados.

Uma conclusão só é válida se valer em todos os desenhos possíveis das premissas.

Questões

A negação de "Se o réu é culpado, então ele será preso" é:

  1. Se o réu não é culpado, então não será preso.
  2. O réu não é culpado e será preso.
  3. O réu é culpado e não será preso.
  4. Se o réu será preso, então ele é culpado.
  5. O réu não é culpado ou não será preso.

Mané: mantém a primeira, nega a segunda, troca por "e".

Uma proposição equivalente a "Se faço exercícios, então durmo bem" é:

  1. Se não durmo bem, então não faço exercícios.
  2. Se durmo bem, então faço exercícios.
  3. Se não faço exercícios, então não durmo bem.
  4. Faço exercícios e não durmo bem.
  5. Faço exercícios ou durmo bem.

Contrapositiva: inverte e nega as duas. B é a recíproca, C é a inversa, D é a negação e E não equivale (o certo seria "Não faço exercícios ou durmo bem").

A negação de "Todos os candidatos estudaram" é:

  1. Nenhum candidato estudou.
  2. Todos os candidatos não estudaram.
  3. Algum candidato estudou.
  4. Algum candidato não estudou.
  5. Pelo menos um candidato estudou.

Todo A é B → Algum A não é B.

Sabe-se que "p ou q" é verdadeira e que p é falsa. Então, necessariamente:

  1. q é falsa
  2. q é verdadeira
  3. "p e q" é verdadeira
  4. "se q, então p" é verdadeira
  5. nada se pode concluir sobre q

Para o "ou" ser V com p F, q tem que ser V. Aí "p e q" é F e "se q, então p" é V → F, ou seja, F.

Quantas linhas tem a tabela-verdade de uma proposição composta por 4 proposições simples?

  1. 4
  2. 8
  3. 12
  4. 32
  5. 16

2⁴ = 16 linhas.
